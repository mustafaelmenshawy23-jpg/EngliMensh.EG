# إنجليمنش | EngliMensh New App

تطبيق مستقل لتعلّم الإنجليزية وفق المناهج المصرية، بهيكل مسارات منفصل عن المشروع القديم.

## المسارات الحالية
- الابتدائي: الصفوف 1–6، ولكل صف مساران:
  - المنهج العادي: Connect.
  - A-Level: Connect Plus (موجود كمسار فارغ لحين توفير ملفات كتبه).
- الإعدادي: الصفوف 1–3، ولكل صف مسار المنهج العادي New Hello ومسار A-Level فارغ.
- الثانوي: الصفوف 1–3، ولكل صف مسار الثانوية العامة ومسار A-Level فارغ.
- البكالوريا المصرية: مسار مستقل وفارغ، لا يختلط بالثانوية العامة.

## سياسة المحتوى
- ملفات PDF الأصلية داخل `public/books` هي المرجع الوحيد للمحتوى.
- لا تُنشأ وحدات أو مفردات أو قواعد أو نصوص أو أسئلة بالتخمين.
- كل عنصر تعليمي يجب أن يحمل مرجع ملف PDF ورقم الصفحة.
- يظل المحتوى غير منشور حتى تتم مراجعته مقابل الكتاب.
- لا تُضاف محتويات لمسارات A-Level أو البكالوريا قبل توافر الكتب الخاصة بها.

## ملفات الكتب الموجودة حاليًا
يوجد 21 ملف PDF في المستودع، بإجمالي يقارب 700.6 MB:
- Connect: كتب الصفوف الابتدائية 1–6 (ترم أول).
- تقييمات ابتدائي: الصفوف 1، 2، 3، 4، 5، 6 (ترم أول/ملفات تقييم).
- New Hello: كتب الصفوف الإعدادية 1–3، إضافة إلى ملفات تقييم ومهام أداء.
- الثانوية العامة: كتب الصفوف 1–3 (ترم أول).

**ملفات Connect Plus غير موجودة حاليًا في مجلدها**، وكذلك كتب البكالوريا. لذلك تم إنشاء مساراتهما فقط وتركهما فارغين. الكتب الموجودة محفوظة ولم تُحذف.

## حالة التنفيذ
- تم استبدال واجهة الوحدات القديمة بواجهة اختيار المرحلة والصف والمسار.
- تم حذف ملفات استخراج Grade 1 القديمة وملفات الألعاب المرتبطة بها من هذا التطبيق الجديد؛ لم تعد جزءًا من بنية المحتوى.
- لم يتم بعد استخراج المحتوى التفصيلي من ملفات PDF الجديدة. ربط المصادر واستخراجها ومراجعتها هي الخطوة التالية.
- لا تعتبر المسارات جاهزة تعليميًا لمجرد ظهورها في الواجهة.

## التشغيل
```bash
cd englimensh-app
npm install
npm run dev
``
